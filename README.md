# MixCoffee 會員資料填寫

會員填寫頁面：可以填姓名、手機、會員卡號（可用相機掃條碼）、出生年月日。

網址：https://qasdfgb-design.github.io/mixcoffee-member/

每筆資料會自動上傳到 Google 試算表「MixCoffee 展場收銀紀錄」的「會員資料」頁；沒網路時先存在手機，有網路再自動補傳，上傳成功後就從手機刪掉。查看會員資料請直接打開該試算表（頁面上沒有店家專區）。

## 展場收銀（pos.html）

咖啡展用的收銀系統：點商品結帳、自動算組合價、記錄庫存和補貨、每日統計。
多支手機會透過 Google 試算表「MixCoffee 展場收銀紀錄」自動同步。

網址：https://qasdfgb-design.github.io/mixcoffee-member/pos.html

## 營收報表（report.html）

只給老闆看的每日營收、庫存、訂單紀錄（收銀頁不顯示營收）。

網址：https://qasdfgb-design.github.io/mixcoffee-member/report.html
